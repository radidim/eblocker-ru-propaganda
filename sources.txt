# Допълнителни (незадължителни) източници за domains-base.txt
#
# Всеки ред = един URL към суров (raw) текстов файл с домейни
# (обикновен domain list или /etc/hosts формат). Скриптът приема и двата
# формата и автоматично премахва невалидните редове (напр. easylist/adblock
# синтаксис, коментари, IP адреси).
#
# Как да добавиш източник:
#   1. Намери суров ("raw") текстов линк към списъка (не HTML страница).
#   2. Провери го ръчно поне веднъж - публичните списъци за
#      руска пропаганда/дезинформация са малко и не винаги добре поддържани.
#   3. Разкоментирай/добави реда по-долу.
#
# Пример (само илюстрация на формата - НЕ е активиран, провери линка сам):
# https://raw.githubusercontent.com/example-org/example-repo/main/list.txt
#
# По подразбиране файлът е празен -> скриптът използва само domains-base.txt.
